# AI Arena — Control Room Engineering Standards

Questo repository contiene le procedure trasversali usate per gestire piu prodotti software senza confondere codice, infrastrutture, dati o deploy.

La regola principale e semplice: **nessuna azione di scrittura o deploy parte prima che il progetto sia identificato tramite fingerprint tecnici indipendenti**.

Documenti principali:
- `skills/project-control/SKILL.md` — procedura operativa anti-confusione e cabina di regia;
- `PROJECT_REGISTRY.md` — registro dei progetti e dei loro fingerprint verificati.

Questo repository non deve contenere segreti, token, password, dump di database o dati cliente.
